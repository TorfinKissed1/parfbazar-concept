# Parf Bazar: концепт редизайна

Концепт интернет-магазина: главная, каталог, страница аромата, корзина и оформление заказа.
Каталог, цены и фото флаконов взяты с действующего сайта parfbazar.ru.

## Страницы

- `index.html`: главная. Первый экран со сменой флаконов, хиты, сет «три по 10 мл», подбор по характеру, магазины на карте.
- `catalog.html`: каталог. Фильтр по объёму, цене, характеру, поводу и нотам, поиск, сортировка.
- `product.html?a=sigarets-and-love`: страница аромата. Галерея, выбор объёма, покупка в 1 клик.
- `checkout.html`: оформление заказа.

Новогодняя версия включается параметром `?ny=1` на любой странице и держится при переходах, `?ny=0` её выключает.

## Как устроено

Статичные страницы без сборки: HTML, CSS, JavaScript. Корзина и избранное хранятся в браузере.
Заказы никуда не отправляются.

Подключено извне: шрифты Google Fonts (Sofia Sans Extra Condensed, Golos Text, Spectral) и JS API Яндекс.Карт 2.1.

Локальный запуск: `python -m http.server 8137` в папке проекта, затем открыть `http://localhost:8137`.

## Архитектура

Скрипты подключаются по порядку и складывают всё в один объект `window.PB`.

| Файл | За что отвечает | Чего не делает |
|---|---|---|
| `js/products-data.js` | список ароматов: названия, тексты, цены по объёмам, разделы, характер, ноты | руками не правится |
| `js/store.js` | корзина и избранное в `localStorage`, расчёт сета (каждые три флакона по 10 мл стоят 3 700 ₽) | ничего не рисует, о переменах сообщает событиями `pb:cart` и `pb:fav` |
| `js/ui.js` | карточка аромата, окна, корзина, счётчики, сообщения, появление блоков при прокрутке | не знает о конкретных страницах |
| `js/search.js` | поиск в шапке с подсказками; на каталоге шлёт событие `pb:search` вместо подсказок | сам каталог не фильтрует |
| `js/menu.js`, `css/menu.css` | окно каталога: разделы и выезжающая панель подразделов (коллекции, характер, ноты, для кого, повод, объём) | каталог не фильтрует, только ведёт на него по адресу с условием |
| `js/forms.js` | маска телефона, проверка полей, покупка в 1 клик | данные никуда не отправляет |
| `js/quiz.js` | подбор аромата из трёх вопросов | |
| `js/home.js`, `js/catalog.js`, `js/product.js`, `js/checkout.js` | логика своей страницы | |
| `js/ny.js`, `css/ny.css` | новогодняя версия: гирлянды, снег, акценты, всё под классом `theme-ny` | обычную версию не меняют |

Стили: `css/base.css` (переменные, типографика, кнопки, поля), `css/chrome.css` и `css/shell.css` (шапка, поиск,
нижняя навигация, окна, корзина), `css/card.css` (карточка, цена, сетка, ленты), `css/blocks.css` (подбор, заявка,
экран «заказ принят») и по файлу на страницу. Классы по БЭМ, значения через переменные из `:root`.

Правила, которые держат проект в порядке:

- тексты ароматов попадают в разметку только через `PB.ui.esc()`;
- состояние каталога живёт в адресе страницы: `filter`, `moods`, `notes`, `occasion`, `ml`, `min`, `max`, `sort`, `q`.
  На эти параметры ссылаются меню и главная;
- самые частые ноты считаются один раз в `js/store.js` (`PB.notes`): ими пользуются и фильтр, и меню;
- высоту шапки, строки поиска и нижней навигации задают переменные `--header-height`, `--header-search-height`,
  `--tabbar-height`: всё закреплённое на экране считает отступы от них.

Шапка, подвал и `<head>` у всех страниц общие. Образец лежит в `index.html`, середина остальных страниц в
`tools/pages/`. После правки шапки или середины страницы пересобираются командой
`python -X utf8 tools/build_pages.py`: `catalog.html`, `product.html` и `checkout.html` руками не правятся.

Проверка: `node tools/flow-test.js` при запущенном локальном сервере проходит путь покупателя (подбор, сет,
карточка, товар, покупка в 1 клик, оформление) на ширине 1440 и 390 и печатает, что увидел на странице.
Нужен Playwright.

Внешние зависимости. Без Google Fonts страницы показываются запасными шрифтами. Без Яндекс.Карт на месте
карты остаётся пустая плашка, адреса магазинов рядом с ней видны.

Выкладка: GitHub Pages из ветки `main`. При выкладке менять номер версии в ссылках на стили и скрипты
(`?v=`), иначе браузеры показывают старые файлы из кеша.
